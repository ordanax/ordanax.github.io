## 39. Связки «проблема → решение» из чата (верифицированные)

> Извлечено из экспорта чата «🔥Linux помощь 🔥» (2024–2026): 1465 пар «вопрос → ответ-решение»,
> проиндексированных по reply-цепочкам. Ниже — самые частые связки с РЕАЛЬНЫМИ решениями,
> которые предлагали в чате и которые срабатывали. При написании статьи по теме —
> встроить эти решения как проверенные «практикой сообщества».

### GRUB / загрузка (129 пар — самое горячее)

615. **В | «Ставлю Windows второй системой — какие настройки в GRUB?» → решение: `os-prober`** — из чата:
     «ос-пробер установи» → `sudo pacman -S os-prober` → `grub-mkconfig -o /boot/grub/grub.cfg`.
616. **В | «Помогите установить GRUB для Арча» → решение: две команды** — из чата:
     `grub-install --target=x86_64-efi --efi-directory=<ESP>` затем `grub-mkconfig -o /boot/grub/grub.cfg`.
617. **В | «После перезагрузки вышел Grub и не грузится» → решение: `efibootmgr`** — из чата:
     с live-USB посмотреть записи загрузки: `efibootmgr`, проверить порядок и наличие записи.
618. **В | «Как увидеть лог загрузки Arch? После обновления чёрный экран» → решение: флаги ядра + журнал** —
     из чата: загрузиться с `nosplash debug nomodeset`; причина обычно драйвер; после входа `journalctl -b`.
619. **В | «Разметка и установка вручную» → решение: последовательность fdisk** — из чата:
     `fdisk -l` → `fdisk /dev/имядиска` (n, w) → `mkfs.fat -F 32 /dev/част2` → `mkfs.ext4 /dev/част1`
     → `mount /dev/част1 /mnt` → `mount /dev/част2 /mnt/boot`.

### pacman / обновление (92 пары)

620. **В | «GPG-ключи pacman не обновляются» → решение: переустановка keyring + refresh** — из чата:
     `pacman -S archlinux-keyring` → `pacman-key --refresh`; при отсутствии Tor: `pacman -Sy archlinux-keyring`.
621. **В | «Отвлёкся и не ввёл sudo при обновлении yay — теперь ошибка» → решение: полный -Syu, не частичный** —
     из чата: частичное обновление ломает систему; докончить `sudo pacman -Syu` (или `yay -Suy`),
     затем пересобрать AUR-пакеты. Пересекается с темой 21 (почему partial — боль).
622. ✅ **С | «Зеркала Ubuntu/репозитории недоступны при обновлении» → решение: смена DNS/зеркал** —
     из чата: «попробуй днски сменить» + зеркала; для Arch — тема 101 (mirrorlist/reflector).
623. **В | «Ошибка после `yay -Suy`» → решение: не смешивать yay и sudo pacman конкурентно** —
     из чата: дождаться завершения; проверить `/var/lib/pacman/db.lck`.

### NVIDIA (86 пар)

624. **В | «Как поставить драйвер NVIDIA» → решение: полный набор пакетов** — из чата:

625. **В | «Старая видеокарта — какие дрова?» → решение: legacy-серия** — из чата:
     `yay -S nvidia-390xx-dkms linux-headers` (для совсем старых карт).
626. **В | «Как удалить драйвер NVIDIA полностью» → решение: purge** — из чата:
     `sudo pacman -Rns nvidia nvidia-utils` + проверка модулей `dkms status`, чистка `/etc/modprobe.d`.
627. **В | «Переключил на режим “nvidia: производительность”, Steam не заходит» → решение: prime/DRI_PRIME** —
     из чата (Mint, но механика общая): запуск с `prime-run` / `DRI_PRIME=1`, проверить `nvidia-smi`.
628. **С | «Чёрный экран при старте (Intel+nvidia)» → решение: флаги ядра** — из чата:

629. **С | «Куда писать параметры ядра» → решение: GRUB_CMDLINE_LINUX_DEFAULT** — из чата +

### Диски / fstab / монтирование (81 пара)

630. **В | «Как смонтировать ISO» → решение: loop** — из чата: `sudo mount -o loop /path/to/iso /mnt`.

632. **С | «После правки fstab — как перечитать без перезагрузки» → решение: remount** —

### AUR (28 пар)

634. **В | «AUR блокируется / недоступен» → решение: зеркала/прокси утилиты (НЕ VPN!)** —
