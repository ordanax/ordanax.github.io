Установка Arch Linux 2026 это загрузка ISO-образа, разметка диска через fdisk, установка базовых пакетов через pacstrap и настройка системы через arch-chroot. Весь процесс занимает 30–40 минут при стабильном интернете и сводится к выполнению одной команды за другим.

## Что понадобится перед установкой

USB-флешка на 2 гигабайта или больше, стабильное интернет-соединение и компьютер с процессором x86_64. Arch официально не поддерживает Secure Boot при загрузке установочного носителя — его придётся отключить в настройках прошивки. Если раньше ты уже работал с Arch, глянь [чек-лист установки](https://ordanax.github.io/chek-list-po-ustanovke-archlinux-2019) — там краткий напоминальный список для тех, кто обновляет навыки.

Скачай ISO-образ со страницы [archlinux.org/download](https://archlinux.org/download/) и запиши его на флешку любым удобным способом — dd, Ventoy, Rufus. Затем загрузись с флешки, выбрав «Arch Linux install medium» в меню загрузчика.

## Как подключиться к сети из live-окружения

Сначала проверь, видит ли система сетевой интерфейс:

```bash
ip link
```

Для проводного подключения кабель вставлен — и сеть работает. Для Wi-Fi используй iwctl:

```bash
iwctl
station wlan0 connect "твоё-имя-сети"
exit
```

Убедись, что интернет доступен:

```bash
ping archlinux.org
```

Хотя бы три-четыре пинга с нормальным временем отклика — и можно двигаться дальше. Для настройки зеркал перед установкой есть отдельная статья про [настройку mirrorlist](https://ordanax.github.io/arch-linux-mirrorlist-nastroyka), но пока хватит заводских зеркал.

## Как разметить диск для Arch Linux

Определи диск, на который будешь ставить систему:

```bash
fdisk -l
```

Запусти утилиту разметки (замени `/dev/sda` на свой диск):

```bash
fdisk /dev/sda
```

Для UEFI-системы нужно два раздела. Создавай их так:

1. **EFI-раздел** — жми `n`, потом при запросе последнего сектора введи `+1G` (получится раздел в 1 ГБ).
2. **Корневой раздел** — снова `n`, остальные секторы пойдут под корень.

После разметки жми `w` — изменения запишутся на диск. Вот команда-шпаргалка: `n` создаёт раздел, `w` записывает и выходит.

## Как отформатировать разделы

```bash
mkfs.fat -F 32 /dev/sda1
mkfs.ext4 /dev/sda2
```

Первый раздел — EFI, второй — корень. Если на диске уже был EFI-раздел от другой системы, не форматируй его вслепую — потеряешь загрузчик.

## Как смонтировать разделы и установить систему

```bash
mount /dev/sda2 /mnt
mount --mkdir /dev/sda1 /mnt/boot
```

Корневой раздел монтируется в `/mnt`, EFI-раздел — в `/mnt/boot`. Проверь вывод `mount`, чтобы убедиться: оба раздела на месте.

Теперь ставим базовые пакеты. Вот команда, которую я использую на каждом новом Arch:

```bash
pacstrap -K /mnt base linux linux-firmware
```

Флаг `-K` создаёт ключи pacman для новой системы. Параметр `base` — минимальный набор для работы системы, `linux` — ядро, `linux-firmware` — прошивки для большинства железа. Микрокод процессора ставят отдельным пакетом: для Intel — `intel-ucode`, для AMD — `amd-ucode`.

## Как сгенерировать fstab и войти в систему

```bash
genfstab -U /mnt >> /mnt/etc/fstab
```

Genfstab пропишет разделы по UUID — это надёжнее, чем по именам устройств. Проверь содержимое fstab:

```bash
cat /mnt/etc/fstab
```

Должны быть две строки с UUID — под корень и под boot. Если всё ок, заходим в новую систему:

```bash
arch-chroot /mnt
```

Теперь ты внутри Arch. Осталось настроить базовые параметры.

## Как настроить часы, локаль и hostname

Часовой пояс:

```bash
ln -sf /usr/share/zoneinfo/Europe/Moscow /etc/localtime
hwclock --systohc
```

Локаль. Отредактируй `/etc/locale.gen` и раскомментируй нужные строки:

```bash
en_US.UTF-8 UTF-8
ru_RU.UTF-8 UTF-8
```

Генерация локалей:

```bash
locale-gen
```

Создай файл `/etc/locale.conf`:

```bash
echo 'LANG=en_US.UTF-8' > /etc/locale.conf
```

Имя хоста — придумай любое, напиши его в `/etc/hostname`:

```bash
echo 'myarch' > /etc/hostname
```

## Как установить загрузчик

Для UEFI-систем проще всего GRUB. Установи пакеты:

```bash
pacman -S grub efibootmgr
```

А затем установи и сгенерируй конфигурацию:

```bash
grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB
grub-mkconfig -o /boot/grub/grub.cfg
```

Альтернатива — systemd-boot, он уже стоит в базовой установке. Достаточно одной команды:

```bash
bootctl install
```

Какой загрузчик выбрать — личное дело. GRUB проще в настройке, systemd-boot легче и быстрее стартует.

## Как задать пароль и создать пользователя

Пароль root:

```bash
passwd
```

Пользователя создавай командой `useradd` с флагом `-m` (домашняя директория) и добавь в группу wheel:

```bash
useradd -m -G wheel твоё-имя
passwd твоё-имя
```

Для работы `sudo` установи пакет и раскомментируй строку `%wheel ALL=(ALL:ALL) ALL` в файле `/etc/sudoers` через `visudo`.

## Как завершить установку

Выйди из chroot, отмонтируй разделы и перезагрузись:

```bash
exit
umount -R /mnt
reboot
```

Не забудь вынуть установочную флешку. Если всё сделано правильно, появится приглашение логина. Если не грузится — не паникуй, разбор типичных проблем есть в статье про [чёрный экран после установки](https://ordanax.github.io/ne-gruzitsya-posle-ustanovki-chernyi-ekran).

## Частые вопросы

**Сколько места нужно для базовой установки?**
Минимум 2 ГБ, но на практике выдели 20–30 ГБ под корень — с запасом под обновления и кэш пакетов.

**Можно ли ставить Arch без интернета?**
Формально да, но pacstrap тянет пакеты из сети. Офлайн-установка требует заранее скачанных пакетов и локального кэша — это отдельная тема.

**Обязательно ли делать отдельный EFI-раздел?**
Для UEFI-систем — да, это требование. Для BIOS/MBR такой раздел не нужен, там GRUB пишется в MBR.

**GRUB или systemd-boot — что выбрать новичку?**
GRUB проще, потому что конфигурируется одной командой, а другие ОС находит через os-prober (его включают вручную). systemd-boot минималистичнее, но потребует ручной настройки записей загрузки.

**Что делать сразу после первой загрузки?**
Настроить зеркала pacman, обновить систему (`pacman -Syu`) и поставить нужные пакеты.

## Заключение

Полная установка Arch Linux 2026 сводится к простой последовательности: загрузка ISO, разметка через fdisk, форматирование, pacstrap, genfstab, arch-chroot, настройка locale и загрузчика. Ничего магического — каждая команда делает одну вещь. Пройдись по шагам, проверяй вывод — и Arch заведётся.
