Первый час после установки Arch Linux — это смена пароля root, создание пользователя с sudo, полное обновление системы через `pacman -Syu` и установка базовых пакетов для жизни. Весь процесс занимает 20–30 минут и сводится к нескольким командам. Ниже — порядок действий, который я повторяю на каждом новом Arch.

## Что сделать в первый час после установки

Сразу после первой загрузки не спеши ставить окружение и кастомизировать всё подряд. Сначала база, потом красота. Вот чек-лист:

1. Войти под root и сменить пароль.
2. Создать пользователя и настроить sudo.
3. Обновить систему — только `pacman -Syu`.
4. Поднять сеть: NetworkManager или systemd-networkd.
5. Поставить базовые пакеты: редактор, htop, fastfetch, терминал.
6. Проверить время и синхронизацию.
7. Ограничить журнал systemd, чтобы он не съел диск.

Каждый пункт занимает пару минут. Пройдёмся по всем.

## Как войти в систему и сменить пароль root

После установки ты заходишь под root — пароль задавался на последнем шаге установки. Если ты его не задал или забыл, загрузись с live-USB, примонтируй корневой раздел и сбрось пароль через arch-chroot.

Сменить пароль root:

```bash
passwd
```

Система попросит ввести новый пароль дважды. Пароль не должен быть коротким — root это главный аккаунт системы. Дальше создаём обычного пользователя.

## Как создать пользователя и настроить sudo

Работать под root постоянно — плохая привычка. Одна опечатка в команде — и система в лучшем случае переустановлена. Создай обычного пользователя и дай ему права через sudo.

```bash
useradd -m -G wheel твоё-имя
passwd твоё-имя
```

Флаг `-m` создаёт домашнюю директорию, группа `wheel` — будущие права sudo. Теперь установи sudo и разреши группе wheel выполнять команды:

```bash
pacman -S sudo
visudo
```

В файле `/etc/sudoers` раскомментируй строку `%wheel ALL=(ALL:ALL) ALL`. Подробный разбор с группами и нюансами — в статье про [создание пользователя](https://ordanax.github.io/sozdanie-polzovatelya-useradd).

## Как обновить систему безопасно

Arch — rolling release, обновления выходят постоянно. Первое обновление после установки обязательно: между выпуском ISO и сегодняшним днём вышло много новых версий пакетов.

```bash
pacman -Syu
```

Одна команда — и всё. Никогда не запускай `pacman -Sy` отдельно: она обновляет только базы пакетов без самой системы, и следующая установка может сломать зависимости. Частичные обновления в Arch не поддерживаются — это правило номер один. Перед обновлением стоит глянуть новости на archlinux.org: иногда пакеты требуют ручных действий.

## Как настроить сеть: NetworkManager или systemd-networkd

Если сеть уже работает — пропусти этот шаг. Если нет, поставь NetworkManager — самый простой вариант для десктопа:

```bash
pacman -S networkmanager
systemctl enable --now NetworkManager
```

Wi-Fi подключается через `nmcli` или графический апплет. Минималистам подойдёт systemd-networkd — он уже в системе, настраивается файлами в `/etc/systemd/network/`. Для сервера или статического IP это лучший выбор.

## Какие пакеты поставить сразу

Минимальный набор для комфортной жизни в терминале:

```bash
pacman -S nano htop fastfetch ghostty
```

- `nano` — простой редактор для правки конфигов (vim — если ты уже с ним дружишь);
- `htop` — мониторинг процессов и нагрузки;
- `fastfetch` — красивая сводка о системе при входе, настройка описана в статье про [fastfetch](https://ordanax.github.io/fastfetch-konfiguraciya);
- `ghostty` — быстрый GPU-терминал, [конфигурация Ghostty](https://ordanax.github.io/ghostty-terminal-konfiguraciya) — отдельная тема.

Зеркала для pacman уже настроены при установке. Если хочешь ускорить загрузку пакетов — статья про [настройку mirrorlist](https://ordanax.github.io/arch-linux-mirrorlist-nastroyka) поможет выбрать самые быстрые.

## Как проверить время и синхронизацию

Неправильное время ломает HTTPS, git и логи. Проверь:

```bash
timedatectl status
```

Если часовой пояс не твой — задай его:

```bash
timedatectl set-timezone Europe/Moscow
```

Синхронизация времени через systemd-timesyncd включается одной командой:

```bash
timedatectl set-ntp true
```

После этого время будет поддерживаться автоматически.

## Как ограничить журнал journald

Журнал systemd по умолчанию может расти до 10% размера корневого раздела. На маленьком диске это десятки гигабайт логов. Ограничь его в `/etc/systemd/journald.conf`:

```ini
SystemMaxUse=500M
```

Раскомментируй строку и перезапусти службу:

```bash
systemctl restart systemd-journald
```

Теперь журнал не съест диск. Проверить текущий размер можно командой `journalctl --disk-usage`.

## Частые вопросы

**Нужно ли обновлять систему сразу после установки?**
Да. Между выпуском ISO и установкой проходит время, и пакеты в системе устаревают. `pacman -Syu` приведёт всё к актуальному состоянию.

**Почему нельзя делать pacman -Sy?**
`-Sy` обновляет только базы пакетов. Следующая установка может взять новые версии из баз и поставить их поверх старых файлов — получишь сломанные зависимости. Только полное обновление `-Syu`.

**NetworkManager или systemd-networkd?**
Для десктопа с Wi-Fi — NetworkManager, он проще. Для сервера и статического IP — systemd-networkd, он уже в системе и настраивается текстовыми файлами.

**Что делать, если забыл пароль root?**
Загрузиться с live-USB, примонтировать корневой раздел, войти через arch-chroot и выполнить `passwd`.

**Сколько места занимает журнал journald?**
По умолчанию до 10% размера корневого раздела. Ограничение `SystemMaxUse=500M` в journald.conf решает проблему.

## Заключение

Первый час после установки Arch — это семь простых шагов: пароль root, пользователь с sudo, обновление, сеть, базовые пакеты, время и лимит журнала. Ничего лишнего, всё по делу. Пройдись по чек-листу — и система готова к нормальной работе. Дальше можно ставить окружение, настраивать терминал и заниматься красотой.
