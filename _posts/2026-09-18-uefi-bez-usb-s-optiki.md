UEFI-загрузка Arch Linux без USB-флешки вполне реальна: ISO-образ Arch — гибридный (isohybrid), он поддерживает загрузку через UEFI с CD/DVD, SD-карты и даже с жёсткого диска. У тебя есть оптический привод — запиши на DVD. Есть кардридер — используй SD-карту. А если и флешки, и привода нет — подними загрузчик с диска через GRUB или стартань по сети через PXE.

## Как загрузить ISO без флешки

Стандартный Arch ISO построены инструментом [archiso](https://wiki.archlinux.org/title/Archiso) и содержат два загрузчика: syslinux для BIOS и GRUB (или systemd-boot) для UEFI. Благодаря isohybrid-записи один и тот же образ грузится и с USB, и с оптического диска, и с flash-накопителя вроде SD-карты. Главное — правильно записать его на целевой носитель.

Если речь о PC с SATA/DVD-приводом — проще всего взять blank DVD-R и записать образ. Если на плате есть SD-слот (бывает на мини-ПК и NUC) — SD-карта будет работать точно так же, как USB-флешка. Если носителей нет совсем — остаётся вариант с GRUB-запуском ISO с внутреннего диска или PXE по сети.

## Как записать Arch на оптический диск

Для записи ISO на CD или DVD команда `dd` не подойдёт — она пишет побайтово, а оптический привод требует специального протокола. Используй `cdrecord` (пакет `cdrtools`) или графический Brasero.

Установи утилиту:

```bash
sudo pacman -S cdrtools
```

Запиши ISO на диск:

```bash
sudo cdrecord -v dev=/dev/sr0 speed=4 archlinux-2026.09.01-x86_64.iso
```

Параметр `dev=/dev/sr0` — твой привод. Если приводов несколько, проверь через `lsblk`. После записи извлеки диск и выбери его в меню загрузки UEFI (обычно F12 или F8 при старте).

**Важно:** не используй удивительные «умные» записыватели вроде etcher или UNetbootin — они ломают структуру isohybrid-образа. Записывай «как есть».

## Как записать Arch на SD-карту

SD-карта в кардридер — это тот же блочный носитель, что и USB-флешка. Команда стандартная:

```bash
sudo dd bs=4M if=archlinux-2026.09.01-x86_64.iso of=/dev/sdX conv=fsync status=progress
```

Здесь `/dev/sdX` — имя устройства SD-карты. Проверь через `lsblk` перед записью. Не путай с разделом (`/dev/sdX1`), указывай весь диск.

На мини-ПК и NUC с встроенным SD-слотом загрузка с карты работает из коробки — в BIOS/UEFI выбери SD-карту как первое загрузочное устройство. Удобно держать такую карту как «аварийный installer» на случай, если флешка была отдана кому-то другому.

## Почему чистый ISO не грузится: hybrid-ISO

Многие пытаются «просто записать файл ISO» и получают ошибку загрузки. Дело в том, что стандартный ISO 9660 — это файловая система для чтения дисков, а не для загрузки. Arch ISO использует isohybrid — особый формат, совмещающий El Torito (для CD/DVD) и MBR/GPT-заголовки (для USB/дисков).

На DVD это работает через El Torito: прошивка UEFI видит на диске загрузочную запись и стартует GRUB. На USB и SD-карте — через isohybrid MBR/GPT-слой: прошивка видит загрузчик как с винчестера.

Если записать ISO через `dd` на CD — не получится, потому что оптический диск требует DAO/TAO записи через специальные SCSI-команды. А вот если записать через `cdrecord` — El Torito автоматически настроится, и диск загрузится.

## Какой ISO выбрать: NETINST или полный

Архивные образы Arch бывают двух размеров: полный (~900 МБ, помечается как `archlinux-YYYY.MM.DD-x86_64.iso`) и bootstrap (~80 МБ, `archlinux-bootstrap-*.tar.gz`). Для загрузки с диска или карты нужен именно полный ISO — он содержит live-окружение и все инструменты для установки.

Если размер носителя ограничен (mini-DVD 700 МБ, старая SD-карта 128 МБ), встанет вопрос. Полный ISO помещается на обычный DVD-R (4.7 ГБ) без проблем. А вот для карточек малого объёма лучше рассмотреть [офлайн-установку с минимумом сети](https://ordanax.github.io/ustanovka-bez-interneta-ofline) — скачай пакеты заранее на другой машине.

## Как загрузиться с жёсткого диска через GRUB

Допустим, у тебя нет ни флешки, ни привода, ни карты — только установленная система (или даже Windows) и Arch ISO на диске. Можно добавить пункт меню GRUB для загрузки ISO напрямую.

Скопируй ISO в безопасное место:

```bash
sudo mkdir -p /boot/iso
sudo cp archlinux-2026.09.01-x86_64.iso /boot/iso/
```

Добавь пункт в конфигурацию GRUB. Отредактируй `/etc/grub.d/40_custom`:

```bash
menuentry "Arch Linux ISO" {
    set isofile="/boot/iso/archlinux-2026.09.01-x86_64.iso"
    loopback loop $isofile
    linux (loop)/arch/boot/x86_64/vmlinuz-linux img_dev=/dev/sda1 img_loop=$isofile
    initrd (loop)/arch/boot/x86_64/initramfs-linux.img
}
```

Обнови GRUB:

```bash
sudo grub-mkconfig -o /boot/grub/grub.cfg
```

При перезагрузке в меню GRUB появится пункт «Arch Linux ISO». Выбери его — загрузится live-окружение прямо с диска.

**Оговорка:** Secure Boot в этом случае не сработает: образ и загрузчик не подписаны. Если Secure Boot активен — отключи его в BIOS или подпиши ядро и загрузчик через [sbctl](https://ordanax.github.io/secure-boot-arch-sbctl).

## Что такое PXE-загрузка по сети

Если есть локальная сеть, Arch можно загрузить через PXE — загрузку по сети без какого-либо физического носителя. На другом компьютере (сервере) подними TFTP/DHCP-сервер, положи ядро и initrd от Arch, и настраиваемая машина скачает их по сети при старте.

Это тема отдельной статьи, но если кратко: подойдут `dnsmasq` (DHCP + TFTP в одном) и стандартные файлы из ISO. На целевом ПК в BIOS включи Network Boot / PXE. Подробнее — в [руководстве по USB-flash-носителям ArchWiki](https://wiki.archlinux.org/title/USB_flash_installation_medium).

## Частые вопросы

### Можно ли установить Arch без USB и без интернета?

Да, но это нетривиально. Заранее скачай пакеты на другой машине, перенеси их на целевой ПК (по LAN, через внешний диск) и используй [офлайн-установку](https://ordanax.github.io/ustanovka-bez-interneta-ofline). Оптический диск или SD-карта с ISO решают проблему загрузки, но для пакетов всё равно нужен источник — локальный репозиторий или зеркало.

### Чем Ventoy лучше простой записи ISO?

[Ventoy](https://ordanax.github.io/ventoy) позволяет держать на флешке несколько ISO и выбирать при загрузке. Простая запись через `dd` даёт один образ. Но Ventoy работает только с USB — на DVD и SD-карту его не поставишь, да и UEFI-совместимость у Ventoy бывает капризной.

### Почему `dd` не работает для записи на DVD?

`dd` выполняет побайтовую копию, а оптический привод принимает команды через SCSI-протокол (MMC). Для записи нужен `cdrecord` или `xorriso`, которые формируют сессию правильно. Простое копирование файла на `/dev/sr0` не создаст загружающий диск.

### SD-карта не загружается в UEFI — что делать?

Проверь, что карта отформатирована как isohybrid (то есть записана через `dd`, а не отформатирована в FAT32 с копированием файлов). Также убедись, что в BIOS включена загрузка с USB-устройств (SD-карта через кардридер видна как USB). Некоторые прошивки требуют включить Legacy USB Support даже для UEFI-режима.

## Заключение

UEFI-загрузка Arch Linux не ограничена USB-флешкой. Оптический привод, SD-карта, внутренний диск с GRUB — всё это рабочие варианты. Ключевой момент: Arch ISO гибридный, и при правильной записи он стартует практически откуда угодно.
