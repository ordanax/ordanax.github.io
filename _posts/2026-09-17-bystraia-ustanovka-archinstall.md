archinstall — официальный скрипт для автоматизации установки Arch Linux, встроенный в каждый установочный образ с 2021 года. Запускается одной командой и проводит через интерактивное меню: от выбора диска до настройки рабочего стола. Скорость — главное преимущество: установка занимает 10-15 минут вместо часа ручной работы. Но за скорость платишь контролем — скрипт принимает часть решений за тебя.

## Что такое archinstall

archinstall — это Python-скрипт, который Arch Linux добавил в состав официальных ISO-образов. Он не заменяет ручную установку, а предлагает альтернативный путь: вместо того чтобы вручную прописывать `pacstrap`, `genfstab` и настраивать загрузчик, ты отвечаешь на вопросы в меню.

Скрипт работает по принципу guided installer — проводит пошагово через все этапы и автоматически генерирует команды под капотом. Если хочешь, можешь запустить его с готовым JSON-конфигом и вообще без интерактива:

```bash
archinstall --config config.json --creds creds.json
```

Но чаще всего люди просто пишут `archinstall` и идут по меню.

## Как запустить установку

Загрузился с флешки, подключился к сети и набираешь:

```bash
archinstall
```

Перед запуском рекомендую обновить сам скрипт — в ISO может лежать устаревшая версия (образ обновляется раз в месяц):

```bash
pacman -Sy archinstall
```

После запуска откроется текстовое меню. Первая опция — выбор языка интерфейса. Дальше по порядку: зеркала, диск, шифрование, сеть, пользователи, профиль, загрузчик, аудио.

## Что выбрать в меню archinstall

Вот основные пункты и дефолтные значения, которые скрипт предлагает по умолчанию:

**Зеркала (Mirror configuration).** archinstall покажет список регионов и предложит выбрать ближайшие. Можно оставить дефолтные из ISO или вручную прописать свои серверы.

**Диск и разметка (Disk configuration).** Три варианта:

- **Guided — entire disk** — скрипт сам разметит весь диск. Простой вариант, но не подходит для дуалбута.
- **Best-effort** — попытается разметить с учётом текущих разделов.
- **Manual partitioning** — полный контроль: ты создаёшь разделы вручную.

**Файловая система.** Доступны ext4, btrfs, xfs, f2fs. По умолчанию — ext4. Если выбираешь btrfs, можно сразу настроить снапшоты с подтомами `@home` и `@root`.

**Шифрование диска (Disk encryption).** Опция LUKS2. Скрипт попросит пароль и зашифрует корневой раздел. Для дуалбута с Windows это удобно — шифруешь только Linux-сторону.

**Сеть (Network).** На выбор: NetworkManager (дефолт), systemd-networkd или копирование сетевой конфигурации с ISO. Если ты настроил Wi-Fi через `iwctl` перед запуском archinstall, скрипт скопирует эту конфигурацию на установленную систему.

**Пользователи.** Создание root-пароля и обычного пользователя с правами sudo (группа wheel). Оставить root-пароль пустым — отключить root-вход, работать только через sudo.

**Профиль (Profile).** Готовые наборы пакетов: десктоп-окружения (KDE Plasma, GNOME, XFCE, Hyprland и другие), оконные менеджеры, серверные профили. Если ставишь [GNOME](https://ordanax.github.io/gnome-ustanovka-linux) или [Hyprland](https://ordanax.github.io/hyprland-arch-linux), скрипт поставит всё необходимое — от пакетов до служб. Выбор профиля экономит время, но устанавливает больше, чем тебе реально нужно.

**Загрузчик (Bootloader).** На UEFI по умолчанию — systemd-boot. Также доступны GRUB и Limine. У systemd-boot есть опция Unified Kernel Image (UKI). На BIOS доступны только GRUB и Limine.

**Аудио.** PipeWire (по умолчанию в 2026 году) или PulseAudio. PipeWire — стандартный выбор, он заменяет PulseAudio и поддерживает видеостриминг через PipeWire-Pulse.

## Когда archinstall не подходит

archinstall — хороший инструмент, но не универсальный. Вот сценарии, где лучше ставить Arch вручную:

**Кастомная разметка.** Если у тебя несколько дисков, отдельные разделы под `/boot`, `/home`, `/var`, `/tmp` с разными опциями монтирования — скрипт не даст нужной гибкости.

**LVM.** archinstall не поддерживает настройку LVM из коробки. Если планируешь логические тома и снапшоты — ставь вручную. Подробнее — в [пошаговом руководстве по установке Arch Linux 2026](https://ordanax.github.io/ustanovka-archlinux-2026-poshagovaya).

**Нестандартные сценарии шифрования.** LUKS2 через archinstall работает, но если нужны расширенные опции — ключевые файлы, несколько паролей, шифрование `/boot` — ручная установка проще.

**Дуалбут с другим Linux-дистрибутивом.** Если на диске уже есть Linux и нужно аккуратно разместить Arch рядом с сохранением текущего загрузчика — автоматика может навредить. Вот [чек-лист установки](https://ordanax.github.io/chek-list-po-ustanovke-archlinux-2019) для тех, кто делает это вручную.

**Изучение системы.** Если цель — понять, как работает Arch, а не просто получить рабочую систему, ручная установка учит гораздо больше. Сравни с [установкой за 15 минут](https://ordanax.github.io/ustanovka-archlinux-2019-za-15-minut), где каждый шаг прописан вручную.

## Частые вопросы

**Можно ли использовать archinstall для дуалбута с Windows?**

Да, через Manual partitioning. Выбери этот пункт, найди свободное место на диске, создай разделы вручную и назначь точку монтирования `/boot` на существующий EFI-раздел.

**Что будет, если оставить root-пароль пустым?**

Root-аккаунт отключится. Вход под root будет невозможен, всё — через sudo. Если не создашь пользователя с правами sudo, система заблокирует тебя.

**archinstall обновился, и меню изменилось. Версия в ISO устарела?**

Обнови скрипт перед запуском: `pacman -Sy archinstall`. В ISO может лежать версия месячной давности.

**Можно ли автоматизировать установку без меню?**

Да. Сгенерируй JSON-конфиг через `archinstall --dry-run`, отредактируй его и запусти с параметрами `--config` и `--creds`. Это полезно для клонирования настройки на нескольких машинах.

**Какой профиль выбрать новичку?**

Для десктопа — KDE Plasma или GNOME. Оба работают из коробки, не требуют ручной настройки служб. XFCE — более лёгкий вариант для слабых машин.

## Заключение

archinstall — реальный способ поставить Arch за 10-15 минут без запоминания команд. Скрипт делает разметку, ставит пакеты, настраивает загрузчик и создаёт пользователя. Дефолты адекватные: systemd-boot на UEFI, ext4, NetworkManager, PipeWire. Для простых сценариев — прямая установка на чистый диск — archinstall работает отлично. Но если нужно LVM, нестандартная разметка или полный контроль над каждым шагом — ставь Arch вручную.
