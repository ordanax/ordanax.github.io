![OpenWrt](../img/openwrt.png){:style="float: left;margin-right: 25px;margin-top: 10px;"} OpenWrt — мощная прошивка для маршрутизаторов с Linux ядром. Позволяет превратить обычный роутер в полноценное сетевое устройство с расширенными возможностями.

## Подготовка к установке

### Проверка совместимости роутера

Перед установкой проверьте, поддерживается ли ваш роутер:
https://openwrt.org/toh/start

### Скачивание прошивки

1. Перейдите на страницу вашего роутера на OpenWrt.org
2. Скачайте стабильную версию прошивки (stable)
3. Сохраните файл на компьютер

## Установка OpenWrt

### Через веб-интерфейс (для некоторых роутеров)

1. Зайдите в веб-интерфейс роутера
2. Перейдите в раздел прошивки/обновления
3. Загрузите файл прошивки OpenWrt
4. Дождитесь завершения установки

### Через TFTP (для большинства роутеров)

1. Подключите роутер к компьютеру через LAN
2. Настройте сетевой интерфейс: IP 192.168.1.2
3. Скачайте TFTP клиент
4. Переведите роутер в режим восстановления
5. Загрузите прошивку через TFTP

## Первичная настройка

### Подключение к роутеру

1. Подключитесь к Wi-Fi сети OpenWrt (пароль по умолчанию)
2. Или подключитесь через LAN кабель
3. Зайдите на http://192.168.1.1
4. Войдите (root без пароля по умолчанию)

### Смена пароля

Сразу смените пароль:
```bash
passwd
```

## Настройка сети

### Настройка WAN

1. Перейдите в Network → Interfaces
2. Отредактируйте интерфейс WAN
3. Выберите тип подключения (DHCP, Static, PPPoE)
4. Настройте параметры провайдера

### Настройка LAN

1. Отредактируйте интерфейс LAN
2. Установите IP адрес (например, 192.168.1.1)
3. Настройте DHCP сервер
4. Установите диапазон IP адресов

### Настройка Wi-Fi

1. Перейдите в Network → Wireless
2. Отредактируйте радиомодуль
3. Установите режим (Access Point)
4. Настройте SSID и шифрование (WPA2-PSK)
5. Установите пароль Wi-Fi

## Настройка PPPoE (для Beeline и других провайдеров)

### Создание PPPoE интерфейса

1. Network → Interfaces → Add new interface
2. Назовите интерфейс (например, WAN_PPPOE)
3. Выберите протокол PPPoE
4. Введите логин и пароль провайдера
5. Сохраните и примените

### Настройка VLAN (если требуется)

1. Network → Switch
2. Настройте VLAN для WAN порта
3. Установите правильный ID VLAN
4. Сохраните настройки

## Настройка DNS

### Изменение DNS серверов

1. Network → DHCP and DNS
2. В поле DNS servers введите:
```
8.8.8.8 8.8.4.4
```

3. Сохраните настройки

### Настройка DNS через dnscrypt-proxy (опционально)

```bash
opkg update
opkg install dnscrypt-proxy
```

Настройте dnscrypt-proxy через `/etc/config/dnscrypt-proxy`.

## Настройка файрвола

### Базовая настройка

1. Network → Firewall
2. Убедитесь, что Zone WAN имеет правильные настройки
3. Zone LAN должна иметь доступ к WAN
4. Включите NAT

### Открытие портов

1. Network → Firewall → Port Forwards
2. Добавьте правило для проброса порта
3. Укажите внутренний IP и порт
4. Сохраните настройки

## Установка пакетов

### Обновление списка пакетов

```bash
opkg update
```

### Установка полезных пакетов

```bash
# SSH ключи
opkg install openssh-keygen

# SFTP сервер
opkg install openssh-sftp-server

# Мониторинг
opkg install htop

# Сетевые утилиты
opkg install tcpdump
```

## Настройка SSH

### Включение SSH

1. System → Administration
2. Включите Dropbear Instance
3. Установите порт (22 по умолчанию)
4. Разрешите доступ по паролю или ключу

### Настройка SSH ключей

```bash
# Генерация ключей на клиенте
ssh-keygen -t rsa -b 4096

# Копирование ключа на роутер
scp ~/.ssh/id_rsa.pub root@192.168.1.1:/tmp/
```

На роутере:
```bash
mkdir -p /etc/dropbear
cat /tmp/id_rsa.pub >> /etc/dropbear/authorized_keys
```

## Резервное копирование

### Резервное копирование конфигурации

1. System → Backup / Flash Firmware
2. Нажмите "Generate archive"
3. Скачайте архив конфигурации

### Восстановление из резервной копии

1. Загрузите архив конфигурации
2. Нажмите "Restore"
3. Дождитесь перезагрузки

## Решение проблем

### Проблема: Нет доступа к интернету

1. Проверьте настройки WAN
2. Проверьте кабель подключения
3. Перезагрузите роутер
4. Проверьте логи: System → Log

### Проблема: Wi-Fi не работает

1. Проверьте включён ли радиомодуль
2. Проверьте страну в настройках Wi-Fi
3. Перезагрузите роутер
4. Обновите прошивку

### Проблема: Медленная скорость

1. Проверьте настройки QoS
2. Отключите ненужные службы
3. Проверьте загрузку CPU
4. Настройте каналы Wi-Fi

## Полезные команды

```bash
# Проверка статуса интерфейсов
ip link show

# Проверка маршрутизации
ip route

# Проверка подключений
netstat -an

# Перезагрузка роутера
reboot

# Проверка свободного места
df -h
```

## Рекомендации

1. **Делайте резервные копии** перед изменениями
2. **Используйте стабильную версию** прошивки
3. **Настройте SSH ключи** для безопасности
4. **Обновляйте прошивку** регулярно
5. **Мониторируйте логи** при проблемах
