Поставить Arch Linux без интернета можно, но только если заранее подготовить пакеты на другом компьютере и перенести их на флешку. Сам pacman работает с локальными файлами без проблем — команда `pacman -U` ставит пакеты прямо из кэша. Сложность в том, что стандартный сценарий установки через `pacstrap` затягивает всё из сети, и без предварительной подготовки обойти это не получится.

## Можно ли поставить Arch без интернета

Да, но с оговоркой. На двух этапах установки Arch нужна сеть: первичная закачка пакетов через `pacstrap` и настройка зеркал. Если заранее скачал все нужные пакеты на машину с интернетом и перенёс на USB-флешку, остальное — чистая локальная работа.

Ключевой момент: pacman оперируется файлами пакетов (`.pkg.tar.zst`) и базами данных. Если оба компонента есть локально, он установит систему без единого запроса к зеркалу. Это штатная возможность пакетного менеджера, а не хак.

## Как собрать набор пакетов на другом ПК

Самый надёжный способ — взять компьютер с Arch и теми же репозиториями, что будут на целевой машине.

### Скачивание через pacman -Sw

Флаг `-Sw` скачивает пакеты в кэш, не устанавливая их:

```bash
sudo pacman -Sw base base-devel linux linux-firmware
```

Команда подтянет также все зависимости. Кэш сохранится в `/var/cache/pacman/pkg/`.

### Полный список для базовой установки

Для системы плюс загрузчик и утилиты:

```bash
sudo pacman -Sw base base-devel linux linux-firmware \
  sudo vim nano networkmanager grub efibootmgr \
  dosfstools git
```

Добавь `intel-ucode` или `amd-ucode` под процессор. Для Wi-Fi сразу после установки поставь `wpa_supplicant` и `iwd`, а базовый чек-лист после загрузки — в статье про [первый час после установки Arch](https://ordanax.github.io/pervyi-chas-posle-ustanovki-arch).

### Перенос на флешку

Скопируй кэш на внешний носитель:

```bash
cp -r /var/cache/pacman/pkg /media/usb/pacman-pkg
```

Возьми также базы данных синхронизации из `/var/lib/pacman/sync/`. Без них pacman не узнает версии пакетов и откажется ставить:

```bash
cp -r /var/lib/pacman/sync/* /media/usb/pacman-sync/
```

## Как ставить пакеты из локальных файлов

### Прямая установка через pacman -U

Когда система загружена, разделы смонтированы, а на другом носителе лежат пакеты:

```bash
pacstrap -U /mnt /mnt/usb/pacman-pkg/*.pkg.tar.zst
```

`pacstrap -U` ставит пакеты из локальных файлов именно в целевой корень `/mnt` (в отличие от `pacman -U`, который из live-окружения установил бы их в саму live-систему). Начни с `base`, потом `linux`, `linux-firmware`, остальное — по порядку. Зависимости `pacstrap -U` разруливает сам — порядок файлов в команде не важен.

### Локальный репозиторий

Для удобства — собери локальный репозиторий утилитой `repo-add`:

```bash
repo-add /media/usb/local.db.tar.gz /media/usb/pacman-pkg/*.pkg.tar.zst
```

Добавь его в `/etc/pacman.conf` на целевой машине:

```ini
[local-repo]
SigLevel = Optional TrustAll
Server = file:///media/usb
```

Pacman увидит пакеты как обычный репозиторий и можно ставить через `-S` как обычно. Удобно, если планируешь повторять установку.

### Ключи и доверие

Перед установкой из локальных файлов убедись, что ключи pacman на месте:

```bash
pacman -Sy archlinux-keyring
```

Без актуальных ключей pacman откажется устанавливать пакеты с ошибкой «invalid or corrupted package (PGP signature)».

## Почему офлайн-установка сложнее в 2026

В 2026 году репозитории Arch обновляются часто, и версии пакетов сдвигаются еженедельно. Это создаёт две проблемы.

**Несовпадение версий.** Если ты скачал пакеты месяц назад, а live-ISO свежий — базы данных могут не совпасть с файлами. Pacman проверяет контрольные суммы и версии из БД, и при несовпадении выдаст ошибку. Решение: качай пакеты в тот же день, когда планируешь установку.

**Обновления пакетов.** Arch — rolling release. Пакеты в кэше быстро устаревают. Если прошло больше недели, зависимости могут «поплыть» и часть пакетов придётся перекачивать.

На практике самый надёжный способ — раздать интернет с телефона через USB-модем или Wi-Fi hotspot. Даже медленное соединение справится с базовой установкой за 10–15 минут. Если совсем никакой сети — создай live-ISO с полным кэшем пакетов на флешке, как описано выше.

Настройка зеркал пригодится, когда сеть появится. Про [настройку mirrorlist](https://ordanax.github.io/arch-linux-mirrorlist-nastroyka) есть отдельная статья, полную последовательность установки смотри в [пошаговом руководстве по Arch Linux 2026](https://ordanax.github.io/ustanovka-archlinux-2026-poshagovaya), а для понимания обновлений — статья про [частичное обновление pacman](https://ordanax.github.io/pacman-chastichnoe-obnovlenie).

## Частые вопросы

**Сколько места нужно на флешке?**
Базовый набор пакетов занимает 800 МБ — 1,2 ГБ. С загрузчиком и утилитами — до 2 ГБ. Флешка на 4 ГБ хватит с запасом.

**Можно ли использовать pacman -U для AUR-пакетов?**
Да, `pacman -U` работает с любым локальным `.pkg.tar.zst`-файлом, включая собранные через `makepkg`. Но для AUR-пакетов нужно сначала собрать их на машине с интернетом.

**Если я скачал пакеты, а потом обновил зеркала?**
Pacman сверит версии пакетов с текущей БД. Если версии не совпадут — выдаст ошибку. Либо обнови кэш, либо ставь локально без обновления БД.

**Какой вариант проще для новичка?**
Раздать интернет с телефона. Серьёзно — две минуты на настройку и никакой головной боли с кэшем и версиями.

## Заключение

Офлайн-установка Arch Linux реальна, но требует подготовки. `pacman -Sw` скачивает пакеты без установки, `pacman -U` ставит их из локальных файлов, а локальный репозиторий через `repo-add` делает процесс удобнее. Главная ловушка в 2026-м — несовпадение версий между кэшем и актуальными базами данных. Если есть хоть малейшая возможность подключиться к сети — используй её.
